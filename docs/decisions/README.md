# Architecture Decision Records

One short file per decision that affects more than one module, the public API, or the
platform strategy. Copy `_TEMPLATE.md`, number it next in sequence, and add it to the
table in `docs/ROADMAP.md`.

Status values: Proposed → Accepted → (Superseded by ADR-NNN).
A Proposed ADR is the plan of record but may still change; an Accepted one is binding.
